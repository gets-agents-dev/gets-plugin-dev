# gets-plugin-dev

Плагин `gets-dev` подключает Claude к Рабочему столу gets: агенты, база и файлы стола.

## Установка

- Claude Desktop: Customize → Plugins → Add marketplace → `gets-agents-dev/gets-plugin-dev`, затем установить плагин `gets-dev` и подключить коннектор на его вкладке Connectors.
- Claude Code: `/plugin marketplace add gets-agents-dev/gets-plugin-dev`, затем `/plugin install gets-dev@gets-plugin-dev`.

Вход — через gets (OAuth) при первом подключении. Ключей и паролей в репозитории нет.

Адрес MCP: https://dev.dard.me/mcp

Файлы создаёт и обновляет основа gets, ручные правки будут перезаписаны.
